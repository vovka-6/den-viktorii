# День Виктории

Планировщик рабочего дня частного педагога: занятия с детьми и подготовка, блог ВК, дом и отдых.
Подсказывает, сколько времени заложить на задачу, и учится на фактическом времени.

- Работает без интернета после первого открытия (устанавливается на главный экран телефона и компьютера).
- Задачи можно надиктовать одной фразой: «завтра в 10 занятие с Мишей, потом пост в ВК», «перенеси уборку на 18:00».
- Данные хранятся на устройстве. По желанию — синхронизация телефона и компьютера через закрытый репозиторий GitHub;
  данные шифруются паролем на устройстве (AES-256-GCM, PBKDF2), на сервер уходит только зашифрованный файл.
- Резервная копия — в «Настройках дня».
