# День Виктории

Планировщик рабочего дня частного педагога: занятия с детьми и подготовка, блог ВК, дом и отдых.
Подсказывает, сколько времени заложить на задачу, и учится на фактическом времени.

- Работает без интернета после первого открытия (устанавливается на главный экран).
- Все задачи хранятся только в браузере телефона и никуда не отправляются.
- Резервная копия — в «Настройках дня».
